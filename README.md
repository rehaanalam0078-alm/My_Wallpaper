# My Wallpaper App 📱✨

My Wallpaper is a modern Android wallpaper application that allows users to explore, download, and set high-quality aesthetic wallpapers with a smooth and responsive experience.

---

## 🚀 Features

- 🔐 User Authentication (Login & Signup)
- 🖼️ High-Quality Wallpaper Collection
- ❤️ Favorite Wallpapers
- 📥 Download Wallpapers
- 📂 Category-Based Browsing
- ⚡ Fast & Smooth UI
- ☁️ Firebase Integration
- 🛠️ Admin Panel for Uploading Wallpapers
- 🌙 Modern Aesthetic Design

---

## 🛠️ Tech Stack

### Frontend
- Android Studio
- Kotlin / Java
- XML UI Design

### Backend & Services
- Firebase Authentication
- Firebase Firestore / Realtime Database
- Firebase Storage
